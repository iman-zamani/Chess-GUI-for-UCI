# Building from source

Requirements: CMake 3.24 or newer, a C++17 compiler, and an internet connection
for the first configure (CMake downloads the pinned dependencies listed below).

```
git clone https://github.com/iman-zamani/Chess-GUI-for-UCI
cd Chess-GUI-for-UCI
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure
./build/chess-gui            # the GUI
./build/chess-cli help       # the command-line tool
```

Platform packages:

- **Linux** (Debian/Ubuntu): `sudo apt install cmake g++ libx11-dev libxrandr-dev libxcursor-dev libxi-dev libudev-dev libgl1-mesa-dev libfreetype-dev`
- **macOS**: the Xcode command line tools and `brew install cmake`. The build also
  produces `build/Chess GUI for UCI.app`, with its data in `Contents/Resources` and an
  ad hoc signature over the whole bundle (without it, a downloaded copy is reported as
  "damaged"). It is not a Developer ID signature, so downloaded copies still need
  **Open Anyway** once (see the README).
- **Windows**: Visual Studio 2022 with the C++ workload, and CMake. Binaries land in
  `build/Release/`.

## Options

| Option | Default | Effect |
|---|---|---|
| `CHESSGUI_BUILD_GUI` | `ON` | `OFF` builds only the core library, `chess-cli` and the tests (no SFML, no display needed) |
| `CHESSGUI_USE_SYSTEM_SFML` | `OFF` | use an installed SFML 3 instead of the pinned copy |
| `CHESSGUI_GUI_TESTS` | `OFF` | register the scripted GUI tests with CTest (they need a display; CI runs them under Xvfb) |

Bundled assets: fonts Cantarell and JetBrains Mono (SIL OFL 1.1), piece sets in
`Resources/pieces/` (each folder has its licence), sounds in `Resources/sounds/`
(CC0, generated by `tools/make_sounds.py`).

## Tests

`ctest` runs the core tests (perft, FEN/SAN/PGN, game tree, UCI wrapper, match
runner, statistics, SPRT, Chess960, Syzygy, the Elo estimator) and the
`chess-cli` tests against a mock UCI engine built from `tests/mock_engine.cpp`;
no network and no real engine are needed. Set `CHESSGUI_SYZYGY_PATH` to a folder
with KQvK, KRvKR and KPvK tables to include the real tablebase probes.

The GUI can be driven by a script (`chess-gui --script tests/gui_smoke.txt`): see
`src/ui_script.hpp` for the steps (click, drag, keys, expected positions,
screenshots).
